目的

看到：主瓣宽度随窗长变化、泄漏随窗类型变化、零填充不增加真实分辨率。

数据说明

  • 来源：本目录 make_signal.py 生成。
  • 许可：本库原创示意数据。
  • 字段：t（s）、x（无量纲幅度）。
  • 采样率：fs = 256 Hz。时长默认 2 s 与 8 s 对照。
  • 成分：10 Hz 与 10.5 Hz 正弦 + 弱 40 Hz + 白噪声。

图表写入 output/（运行后才有）。本轮仓库 不含 运行产物。

预期现象（逻辑预期，非实测）

  • 2 s 矩形窗：10 与 10.5 Hz 可能分不开。
  • 8 s：应能分开。
  • Hann：旁瓣低于矩形，主瓣更宽。
  • 零填充到 8192：曲线更密，分开与否仍取决于有效窗长。

评价指标

峰值频率误差、两峰之间的凹谷深度、旁瓣最高相对电平。未运行则不要填数字。
