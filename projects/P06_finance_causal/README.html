P06 金融时间序列：滚动分解 vs 全序列（防泄漏）

项内容
数据示意合成价格（几何布朗 + 正弦调制），不是行情
状态已整理，未运行验证
关键全序列 EMD/低通 不等于 可交易特征

实验

  1. 合成价格与因果滞后收益标签 \(r_{t\to t+1}\)。
  2. offline_full：对整段价格 filtfilt 或 EMD，用当前点的平滑值当特征。
  3. causal_roll：每个 \(t\) 只用 \(x_{t-L+1:t}\) 做因果 EMA。
  4. 比较：特征与未来收益的相关、转折点处特征是否提前动。

不得把 offline 相关当策略表现。

运行

python3 make_series.py
python3 analyze.py

评价指标

  • 特征与 \(r_{t+1}\) 的相关系数（泄漏诊断，不是 alpha）
  • 转折点附近特征相对价格的超前样本数（offline 往往“超前”）
