# P02 非平稳信号：STFT 与小波时频对比

| 项 | 内容 |
| --- | --- |
| 领域 | 02 信号处理 |
| 数据 | **示意合成**：线性 chirp + 中段脉冲 |
| 采样率 | 512 Hz |
| 状态 | 已整理，未运行验证 |
| 环境 | `03_signal_audio_image_py312`（`scipy` + 可选 `pywt`） |

## 目的

同一信号上看 STFT 固定窗与 CWT 多分辨率的差别。不预先宣布谁更好。

## 运行

```bash
python3 make_signal.py
python3 analyze.py
```

无 `pywt` 时 CWT 段会写入“跳过”。无 matplotlib 则只写数值摘要。

## 预期现象（逻辑）

- STFT 短窗：脉冲时间定位较好，chirp 频率条较糊。
- STFT 长窗：相反。
- CWT（若可用）：脉冲在小尺度更尖；低频 chirp 段尺度拉长。

## 评价指标

脉冲时间定位误差、chirp 脊线相对理论频率的 RMSE。未运行留空。

## 常见错误

用不同色彩映射和不同归一化后肉眼“对比”，却无同一色标或能量定义。
