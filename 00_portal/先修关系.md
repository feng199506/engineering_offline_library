## 硬依赖（缺了会读不懂）

| 主题 | 必须先会 |
| --- | --- |
| DFT 泄漏与窗 | 采样定理、离散内积、主瓣概念 |
| IIR 稳定性 | 差分方程、极点（至少几何直觉） |
| 小波阈值 | 多分辨率、正交性/双正交、噪声模型 |
| EMD/VMD | 瞬时频率的局限；模态混叠现象 |
| Kalman | 高斯、条件期望、状态空间 |
| EKF | KF + 泰勒展开；线性化误差 |
| UKF | KF + 无迹变换；不是“一定比 EKF 好” |
| 粒子滤波 | 重要性采样；退化与重采样 |
| IMU/GNSS 融合 | 坐标、姿态参数化、时间同步 |
| 金融分解特征 | 滚动因果窗口；禁止全序列 IMF |

## 可并行

- 09 工程开发与任何阶段并行。
- 07 通信可与 02 信号实验并行（串口采集）。
- 04 的监督学习可与 03 并行，但深度模型和 KF 不要互相替代。

## 不要颠倒的顺序

1. 先刷飞控再学姿态表示。
2. 先上 CEEMDAN 再理解 FFT 分辨率。
3. 先做深度学习时序预测再学时间切分。
4. 用 x86-64 wheel 在树莓派上装科学栈。
5. 把 `filtfilt` 的图当作实时滤波结果。
