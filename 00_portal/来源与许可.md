## 三类处置

| release_class | 含义 | 公开 GitHub Release |
| --- | --- | --- |
| public | OSI / CC BY / GFDL / IETF / OASIS 等允许再分发（仍须保留声明） | 可以，打包前再核对包内 LICENSE |
| local | 作者提供个人阅读 PDF、CC BY-NC、MIT OCW NC、厂商 datasheet | **不可以**（[`_local_only/`](../_local_only/)、[`docs_html/`](../docs_html/)） |
| link | 付费、登录、版权不明、体积策略放弃 | 无文件 |

## 语言

导读与项目说明为中文。原文以英文开放教材为主，中文优先项为 d2l-zh、Datawhale 笔记。

## 不是已离线的情况

- 目录里只有 URL 的书目
- HTML 镜像失败或只有入口页（dspguide 第一轮）
- IEEE/ASME 原论文
- 视频课
- 完整 ROS 2 / 内核文档树
- 行情数据、CWRU 全库
