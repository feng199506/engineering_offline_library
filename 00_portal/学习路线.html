分阶段学习路线

目标不是“读完所有 PDF”，而是每阶段能 推导一个核心公式、实现一个最小算法、解释一次实验现象。
阶段内资料见各领域导读。本路线是总顺序。

阶段 0 · 工具与纪律（1–3 天）

  • 会用编辑器、终端、Git 记录实验参数。
  • 读 /root/linux_python_offline_resources/guides/离线安装与使用_cn.md（若要跑代码；本轮未安装）。
  • 分清四种状态：仅下载 / 已整理 / 已运行验证 / 已在目标硬件验证。
  • 金融与控制：先读 10_quant_finance/methods/未来信息泄漏.md 中的因果原则，后面所有分解都套用。

产出：能打开一份 Markdown、一份 PDF、一份 Python 文件，并说明它们的许可类别。

阶段 1 · 数学语言（2–4 周）

顺序：线性代数 → 微积分/ODE 直觉 → 概率统计 → 数值计算 → 无约束优化。

必做：

  1. 矩阵乘法、秩、特征分解/SVD 各写一页推导。
  2. 高斯分布、贝叶斯公式、随机过程的平稳与白噪声。
  3. 最小二乘的法方程与条件数。

项目：P07_linreg_from_scratch、P19_opt_least_squares。
环境：01_scientific_notebook_py312（未验证）。

阶段 2 · 信号的时域与频域（3–5 周）

顺序：采样与混叠 → 卷积/相关 → DFT/FFT → 窗与泄漏 → FIR/IIR → STFT → 小波 → EMD 家族。

必做：

  1. 用合成多频信号看到主瓣宽度与旁瓣（P01）。
  2. 同一非平稳信号上对比 STFT 与 CWT（P02）。
  3. 去噪时同时记录 SNR 和 相位/边缘失真（P03）。

不要在没做 P01 之前跳到 VMD。
环境：03_signal_audio_image_*、GNU Octave signal 包（若本机有；本轮未装）。

阶段 3 · 状态、滤波与控制（3–5 周）

顺序：状态空间 → 可观测性直觉 → Kalman → EKF/UKF → 平滑 vs 滤波 → 粒子滤波 → 经典 PID/超前滞后 → 系统辨识入门。

必做：

  1. 线性高斯 KF 手推预测/更新，再对照实现（P05 的 GNSS 位置通道）。
  2. 同一非线性姿态问题比较 EKF 与 UKF（P16），记录是否 未调参。
  3. 明确：RTS 平滑用了未来观测，不能当作机载实时性能。

环境：11_optimization_control_*、01_scientific_notebook_*。

阶段 4 · 数据、模型与时间序列（4–8 周，可与 3 部分重叠）

顺序：数据整理 → 线性模型/树模型 → 深度学习基础 → 时间序列 → 择一：CV / NLP / RL。

必做：滚动窗口、时间切分、禁止打乱时序。
项目：P09_mnist_mlp（入门）、P20_rl_gridworld（入门）、领域进阶用 d2l 章节而非自造大项目。
环境：02_*、04_pytorch_cpu_*、08_rl_basics_*、09_huggingface_llm_*（按需，均未验证）。

阶段 5 · 嵌入式与板端（贯穿，从阶段 2 末开始）

Linux SBC 与 MCU 两条线：

  • SBC：交叉编译概念、设备树、时间戳与时钟源、环形缓冲、实时性是调度问题不是“把 Python 循环写快一点”。
  • MCU：UART 日志、DMA/中断、定点 FIR、CMSIS-DSP 或 kissfft。

项目：P10_serial_logger、P15_wavelet_c、P18_sbc_capture_buffer。
状态：代码 已整理，未在目标硬件验证。镜像在 embedded/linux_sbcs/，未烧录。

阶段 6 · 通信、机器人、工程化（按职业目标选）

  • 通信：UART/I²C/SPI 之后才是 MQTT/Modbus/CAN（P11）。
  • 无人机：先坐标与姿态，再 MAVLink，再 PX4 文档，不要一上来刷飞控（P12）。
  • 工程：测试、API、日志、监控（P13）。没有这一层，前面的实验无法复现。

阶段 7 · 量化（仅在 1、2、4 之后）

必读：全序列 EMD/VMD、零相位 filtfilt、Kalman 平滑在交易里都是 离线 能力。
项目：P06_finance_causal、P14_look_ahead_audit。
禁止把 Yahoo/付费行情当本库已下载数据。本库金融数据为 示意合成。

每周检查问题

  1. 这个算法的假设是什么？打破后会怎样？
  2. 输入输出维度、参数、复杂度各是什么？
  3. 评价指标是否同时覆盖误差与延迟/因果性？
  4. 结果来自合成数据还是真实数据？是否已运行？
