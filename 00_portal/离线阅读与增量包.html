离线阅读与增量资产

阅读

  • 导读与项目：Markdown，用任意编辑器。
  • PDF：_public/ 可随公开包；_local_only/ 仅个人阅读，不要打进 GitHub Release。
  • HTML：docs_html/ 有限镜像，离线用浏览器打开入口页。

增量包原则

原 wheel/deb/镜像 Release 保留，不重打。本目录单独打包：

包名建议内容公开上传
knowledge-guides-projects_*.tar00_portal/ 各领域导读 methods/ projects/是
knowledge-public-vendor_*.tar_public/ + 许可允许的 vendor/（已剔除 NC 与大 wiki）是（逐项核对 LICENSE）
knowledge-vendor-large-wikis_*.tarArduPilot wiki、PX4 user guide、树莓派 documentation 源是（体积大，单独包）
knowledge-local-only_local_only/ docs_html/否，不打包上传
大体积视频 / 完整 ROS / 完整内核 HTML本轮不做—
系统镜像已在实践环境 embedded/linux_sbcs 原包沿用原策略

校验：对每个 tar 写 sha256sum。组合使用：先解压原环境包，再解压 knowledge-guides-projects，再按需解 public vendor / 大 wiki。个人阅读 PDF 留在盘上 _local_only/，不进 Release。

脚本：engineering_offline_library/scripts/make_incremental_assets.sh（排除 _local_only 与 NC vendor）。
