先修

C 的指针与内存模型、Makefile 或 CMake 入门、会用 ls/mount/dmesg。Python 不能替代这一领域的核心。

学习顺序

  1. 用户态：进程、文件描述符、权限、动态库。
  2. 构建：gcc、链接脚本概念、交叉编译前缀 aarch64-linux-gnu-。
  3. 内核与驱动边界：系统调用 vs /dev。LDD3 是历史教材，API 已变，学结构不要抄过时接口上 6.x 内核。
  4. 设备树：硬件描述不是驱动本身。
  5. 调试：gdb、strace、perf、串口 console。
  6. 实时：PREEMPT_RT、优先级、最坏执行时间；Python GIL 不是硬实时方案。
  7. 性能：cache、拷贝次数、零拷贝、绑核。

核心概念

交叉编译产出的二进制取决于 glibc 版本、CPU 架构、ABI。仓库里 Linux x86-64 wheel 不能上 ARM 板。

时钟：CLOCK_MONOTONIC 适合间隔；时间戳对齐传感器用同一时钟域，NTP 会跳变。

环形缓冲：生产者（中断/线程）与消费者解耦。丢样要计数，不能静默覆盖还不报。
