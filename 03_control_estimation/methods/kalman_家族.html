Kalman 家族：KF / EKF / UKF / 平滑 / 粒子滤波

状态：已整理。

共同假设框架

有状态 \(x_k\)、观测 \(y_k\)。滤波器估计 \(p(x_k|y_{1:k})\)（或矩）。模型错则后验错。\(Q,R\) 是模型的一部分，不是装饰。

KF

线性 + 高斯 → 均值协方差闭式。复杂度：状态维 \(n\)、观测维 \(m\) 时，朴素更新 \(O(n^3)\) 量级（协方差预测）。数值要用 Joseph 形式或平方根滤波防 \(P\) 失对称。

EKF

\(x_k=f(x_{k-1},u_{k-1})+w\)，\(y_k=h(x_k)+v\)。雅可比 \(F=\partial f/\partial x\)，\(H=\partial h/\partial x\)。

局限：强非线性下不一致（自认为很准）；需要可微；四元数约束要额外处理。

UKF

选 \(2n+1\) 个 sigma 点，经 \(f,h\) 传播后配矩。无雅可比。参数 \(\alpha,\beta,\kappa\) 改变点的散布。过程噪声若与状态耦合（离散化），实现细节会造成“两个 UKF 对不上”。

不是自动优于 EKF。应以同一条合成轨迹比较 RMSE 与一致性（NEES），并固定随机种子。

平滑

RTS：前向滤波 + 后向递推，\(p(x_k|y_{1:N})\)。离线标定、事后轨迹可以。实时控制、盘中决策不行。固定滞后平滑 \(p(x_k|y_{1:k+\ell})\) 用 \(\ell\) 步未来，延迟 \(\ell\) 个采样。

粒子滤波

从建议分布采样，权重 \(\propto\) 似然。有效样本 \(N_{\mathrm{eff}}=1/\sum w_i^2\) 过小则重采样。局限：维度升高指数级粒子；建议分布差则全死。

传感器融合要点

  • 不同速率：先定义谁驱动时间主钟。
  • 延迟 GNSS：状态要能预测到观测时刻，或增广延迟。
  • 野值：门控（新息马氏距离），不要硬吃。
  • 未建模振动会被 IMU 当成有用加速度。

P05 用合成 2D 匀速 + 位置 GNSS + 加速度计偏差。P16 用欧拉角简化姿态（教学），并写明 不是 飞控级 AHRS。
