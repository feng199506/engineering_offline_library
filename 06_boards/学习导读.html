Linux 开发板学习顺序

  1. 读该型号的 镜像与架构表（embedded/linux_sbcs/OVERVIEW_cn.md）。
  2. 写卡工具在主机 embedded/linux_sbcs/_shared/host_x86_64/（本轮不写卡）。
  3. 串口 console 参数（常见 115200 8N1，以厂商说明为准）。
  4. 采集：I²C/SPI/USB 小数据 → 环形缓冲 → 时间戳 → 再谈 FFT。
  5. 性能：先测单核浮点 FFT 耗时，再决定 Python 还是 C。

树莓派 Bookworm 板端 Python 是 3.11 ARM，与主机 3.10/3.12 x86-64 不混用。

ODROID 官方 Ubuntu 镜像本轮部分 403/404，现有多为 Armbian 社区镜像，不是 Hardkernel 官方系统。

MCU 学习顺序

  1. 主机工具链：arduino-cli、ESP 核心、Pico SDK 源码、OpenOCD（已下载范围见 embedded/README_cn.md）。
  2. 点亮与串口打印。
  3. 定时采样 + 简单 FIR。
  4. CMSIS-DSP 或 kissfft。
  5. 再谈 DMA。

STM32CubeProgrammer 未下载（ST 账号）。ESP32-C5/C6 等新芯片核心 未声明齐全。
